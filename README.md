**已发布 v1.0.1** · 浏览器端三维地质属性建模与空间分析平台。

### ✅ [考勤助手 · LessonSearch](https://github.com/Keleoz-Cyber/LessonSearch)

**已在高校查课工作中投入使用** · 面向现场查课、考勤记录、名单提交、管理员审核与周汇总的 Android 应用。

本地优先架构与 SyncQueue 同步队列支持弱网下记录、恢复联网后同步，配合状态留痕与 Excel 导出形成完整工作流程。

`Flutter` `Drift / SQLite` `FastAPI` `MySQL` `Docker`
